# Practica

Para clinica:

1. Revisa res/values/themes.xml

En el panel izquierdo abre res > values > themes.xml. Debe contener algo así:


<?xml version="1.0" encoding="utf-8"?>
<resources>
    <style name="Theme.ClinicaSaludPlus" parent="android:Theme.Material.Light.NoActionBar" />
</resources>


Para tecsupFit:
Solución
Clic derecho sobre la carpeta values > New > Values Resource File
Nómbralo themes y acepta
Reemplaza su contenido por:


<?xml version="1.0" encoding="utf-8"?>
<resources>
    <style name="Theme.TecsupFit" parent="android:Theme.Material.Light.NoActionBar" />
</resources>
